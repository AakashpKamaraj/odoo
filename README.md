# DayFlow 🌊

### Plan your day. Focus on what matters.

DayFlow is a modern productivity and daily planning web application designed to help users organize tasks, manage schedules, track productivity, and stay focused throughout the day.

## ✨ Features

- 📊 Smart productivity dashboard
- ✅ Task creation, editing, completion, and deletion
- 🔍 Task search, filtering, and sorting
- 📅 Interactive calendar
- 🎯 Daily focus mode with Pomodoro timer
- 📈 Productivity statistics and progress tracking
- 🔥 Daily productivity streak
- 🌙 Light and dark mode
- 👤 User profile and preferences
- 🔔 Toast notifications and reminders
- 📱 Fully responsive UI for desktop, tablet, and mobile
- 💾 LocalStorage-based data persistence

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Chart.js
- Lucide Icons
- LocalStorage
